A streamlined, single-purpose inference pipeline and notebook execution harness for running the pretrained **PolicyGuard-4B** model on the 100 bundled policy-compliance test cases (`policyguard_prompts_100/policyguard_inputs`).

---

## 1. Overview

The pipeline performs a direct, single job:

1. **Loads Model**: Loads `Rakancorle1/PolicyGuard-4B` and its tokenizer on GPU.
2. **Reads Test Cases**: Reads the 100 preformatted `.txt` prompt files from `policyguard_prompts_100/policyguard_inputs`.
3. **Runs Inference**: Sends each prompt to the model with greedy decoding (`do_sample=False`, `max_new_tokens=4`).
4. **Collects Outputs**: Records the exact raw output string of the model as-is (no post-processing, no artificial label conversion) alongside execution latency.
5. **Saves to CSV**: Writes the complete list of results directly to `policyguard_outputs.csv`.

> **Note on Evaluation:** The pipeline does not run automated evaluation or alter model outputs. Test case outputs are recorded raw so you can evaluate them independently against `policyguard_evaluation_ground_truth.csv`.

---

## 2. PolicyGuard-4B Model

- **Hugging Face Model ID:** `Rakancorle1/PolicyGuard-4B`
- **Architecture:** Causal Language Model fine-tuned for policy compliance checks.
- **Decoding:** Greedy token generation (`do_sample=False`, `max_new_tokens=4`).

---

## 3. Output CSV Structure (`policyguard_outputs.csv`)

The generated CSV maps test case IDs directly to raw model outputs:

| Column | Description | Example |
| :--- | :--- | :--- |
| `case_id` | Test case identifier extracted from filename | `TC01`, `TC02` |
| `file_name` | Full input filename | `TC01_student_own_grade.txt` |
| `model_output` | Exact decoded raw text generated by the model | `no_violation` or `violation\n\nvi` |
| `latency_ms` | Inference latency in milliseconds | `24.5` |
| `error` | Error message string if inference failed (empty on success) | `""` |

## 5. Running in Google Colab (`PolicyGuard_100_Test_Cases.ipynb`)

1. Open [Google Colab](https://colab.research.google.com/) and upload `PolicyGuard_100_Test_Cases.ipynb`.
2. Select a GPU runtime: **Runtime -> Change runtime type -> Hardware accelerator: T4 GPU**.
3. Run the cells sequentially:
   - **Cell 1: Environment Setup** — Verifies CUDA GPU and installs dependencies.
   - **Cell 2: Repository Setup** — Clones/pulls the repo and imports `load_model`, `run_inference`.
   - **Cell 3: Load Model** — Loads `Rakancorle1/PolicyGuard-4B` onto GPU memory.
   - **Cell 4: Run Inference** — Processes all 100 test cases and saves to `policyguard_outputs.csv`.
   - **Cell 5: Display Table** — Displays `policyguard_outputs.csv` as an interactive table.
   - **Cell 6: Cleanup** — Frees GPU memory and clears cache.

## 6. Running in Kaggle Notebook

You can run this pipeline for free on Kaggle with dual T4 GPUs (30 hours/week):

1. Go to [kaggle.com/code](https://www.kaggle.com/code) and click **"New Notebook"**.
2. **Import Notebook**:
   - In the menu, go to **File -> Import Notebook**.
   - Under the **GitHub** tab, enter: `https://github.com/AkarshiAaryan/GuardSLM`
   - Select `PolicyGuard_100_Test_Cases.ipynb` (or upload the `.ipynb` file directly).
3. **Enable GPU**:
   - In the right-hand **Notebook Settings** panel, click **Accelerator** and select **GPU T4 x2** (or GPU P100).
4. **Enable Internet (CRITICAL)**:
   - In the right-hand **Notebook Settings** panel, toggle **Internet -> ON** (required to clone repo and download model weights from Hugging Face).
5. **Run the Notebook**:
   - Run Cells 1 through 6 in order.
   - The resulting `policyguard_outputs.csv` is saved in the working directory and can be downloaded from the **Output** tab on the right sidebar.

## 7. Command-Line Usage

You can also run inference directly via the terminal:

### Installation
```bash
git clone https://github.com/AkarshiAaryan/GuardSLM.git
cd GuardSLM
pip install -r requirements.txt
```

### Smoke Test (e.g. first 3 cases)
```bash
python policyguard_pipeline.py --limit 3 --output-csv results/smoke_test.csv
```

### Run All 100 Test Cases
```bash
python policyguard_pipeline.py --output-csv policyguard_outputs.csv
```
